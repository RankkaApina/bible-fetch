# Bible Fetch

To pull bibles for personal bible study use. 

Checks bibles from BibleGateway, Bible.com and Raamattu.fi.

## Usage

```
bible_fetch "<reference>" --version <version>
```

Where reference is something like `GEN 1:2-4` or it should work for one chapter to another like `GEN 1:2-2:4`, but not 100% guaranteed.

and version something like `"NRSVUE"` -> check relevant websites for the tags they use.
